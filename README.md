# data-platform

Оркестрируемая платформа для обработки данных: извлечение из источника → архивация в объектное хранилище (Parquet) → трансформации через dbt/DuckDB → BI-дашборд.

## Стек
- Airflow — оркестрация
- MinIO — объектное хранилище (S3-совместимое)
- dbt + DuckDB — трансформации и тесты
- Metabase — дашборд
- Docker Compose — локальное развёртывание
